# Security Policy

## Supported version

Security fixes are applied to the latest commit on the default branch.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository when it is available. Do not include credentials, personal data, production logs, activation codes, or exploit details in a public issue.

If private vulnerability reporting is temporarily unavailable, open a public issue that requests a private contact channel without disclosing the vulnerability itself.

## Secrets

Never commit API keys, cloud credentials, signing certificates, production environment files, databases, activation codes, or mobile-auth SDK credentials. Revoke exposed credentials before removing them from Git history.
