# 快速开始指南

## 5 分钟快速体验

### 第一步：获取 API 密钥

1. **Claude API**（文本分析）
   - 访问 https://console.anthropic.com/
   - 注册并创建 API Key
   - 复制密钥（格式：`sk-ant-api03-xxxxx`）

2. **Azure TTS**（语音合成）
   - 访问 https://portal.azure.com/
   - 创建"语音服务"资源
   - 获取密钥和区域（如：eastasia）

### 第二步：运行示例代码

```swift
import Foundation

// 1. 创建生成器
let generator = AudioBookGenerator(
    aiApiKey: "你的-claude-api-key",
    ttsApiKey: "你的-azure-tts-key",
    aiProvider: .claude,
    ttsProvider: .azure
)

// 2. 准备小说文本
let text = """
"今天天气真好！"小明高兴地说。

"是啊，我们去公园玩吧。"小红建议道。

两个孩子手拉手，向着公园的方向跑去。
"""

// 3. 生成有声书
Task {
    do {
        let playlist = try await generator.generate(text: text) { progress in
            print("进度: \(Int(progress.progress * 100))%")
        }

        // 4. 播放
        let player = AudioBookPlayer()
        player.load(playlist: playlist)
        player.play()

        print("✅ 成功！共生成 \(playlist.items.count) 个音频片段")
    } catch {
        print("❌ 错误: \(error)")
    }
}
```

### 1. UI 界面开发（优先级：高）

创建 SwiftUI 界面：

```swift
// ContentView.swift
import SwiftUI

struct ContentView: View {
    @StateObject private var viewModel = AudioBookViewModel()

    var body: some View {
        NavigationView {
            VStack {
                // 文本输入区
                TextEditor(text: $viewModel.inputText)
                    .frame(height: 200)
                    .border(Color.gray)

                // 生成按钮
                Button("生成有声书") {
                    viewModel.generate()
                }
                .disabled(viewModel.isGenerating)

                // 进度显示
                if viewModel.isGenerating {
                    ProgressView(value: viewModel.progress)
                    Text(viewModel.statusMessage)
                }

                // 播放控制
                if viewModel.playlist != nil {
                    PlayerControlView(player: viewModel.player)
                }
            }
            .padding()
            .navigationTitle("AI 有声书")
        }
    }
}

// ViewModel
class AudioBookViewModel: ObservableObject {
    @Published var inputText = ""
    @Published var isGenerating = false
    @Published var progress: Double = 0
    @Published var statusMessage = ""
    @Published var playlist: Playlist?

    let generator: AudioBookGenerator
    let player = AudioBookPlayer()

    init() {
        generator = AudioBookGenerator(
            aiApiKey: Config.aiApiKey,
            ttsApiKey: Config.ttsApiKey
        )
    }

    func generate() {
        isGenerating = true

        Task {
            do {
                playlist = try await generator.generate(
                    text: inputText
                ) { [weak self] progress in
                    DispatchQueue.main.async {
                        self?.progress = progress.progress
                        self?.statusMessage = progress.message
                    }
                }

                DispatchQueue.main.async {
                    self.isGenerating = false
                    self.player.load(playlist: self.playlist!)
                }
            } catch {
                DispatchQueue.main.async {
                    self.isGenerating = false
                    self.statusMessage = "错误: \(error.localizedDescription)"
                }
            }
        }
    }
}
```

### 3. 文件导入功能

```swift
// 支持导入 TXT、EPUB、PDF 文件
import UniformTypeIdentifiers

struct DocumentPicker: UIViewControllerRepresentable {
    @Binding var text: String

    func makeUIViewController(context: Context) -> UIDocumentPickerViewController {
        let picker = UIDocumentPickerViewController(
            forOpeningContentTypes: [.text, .plainText],
            asCopy: true
        )
        picker.delegate = context.coordinator
        return picker
    }

    func updateUIViewController(_ uiViewController: UIDocumentPickerViewController, context: Context) {}

    func makeCoordinator() -> Coordinator {
        Coordinator(self)
    }

    class Coordinator: NSObject, UIDocumentPickerDelegate {
        let parent: DocumentPicker

        init(_ parent: DocumentPicker) {
            self.parent = parent
        }

        func documentPicker(_ controller: UIDocumentPickerViewController, didPickDocumentsAt urls: [URL]) {
            guard let url = urls.first else { return }

            do {
                let text = try String(contentsOf: url, encoding: .utf8)
                parent.text = text
            } catch {
                print("读取文件失败: \(error)")
            }
        }
    }
}
```

## 成本估算

### 示例：生成一本 10 万字小说

**AI 分析成本（Claude Sonnet）：**
- 输入：约 150K tokens
- 输出：约 50K tokens
- 成本：约 $1.20

**TTS 成本（Azure）：**
- 字符数：100,000
- 成本：约 ¥11 (约 $1.50)

**总成本：约 $2.70**

### 优化后成本

启用缓存后，相同内容不会重复生成，实际成本会更低。

## 常见问题

**Q: 需要多长时间生成一本小说？**
A: 取决于小说长度和 API 响应速度。1 万字约需 2-5 分钟。

**Q: 生成的音频质量如何？**
A: 使用 Azure Neural Voice，接近真人播音效果。

**Q: 可以离线使用吗？**
A: 生成需要网络，但生成后的音频可以离线播放。

**Q: 支持哪些语言？**
A: 当前主要支持中文，可扩展支持其他语言。

**Q: 如何自定义角色声音？**
A: 使用 VoiceManager 手动为角色分配音色。
