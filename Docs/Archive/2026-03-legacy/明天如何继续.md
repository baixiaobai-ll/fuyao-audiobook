## 🚀 明天启动步骤（5 分钟）

### 第 1 步：启动模拟器和 App

```bash
cd "/path/to/fuyao-audiobook"

# 编译
xcodebuild -project 'AI有声书.xcodeproj' -scheme 'AI有声书' -destination 'platform=iOS Simulator,id=<simulator-id>' -derivedDataPath build build 2>&1 | tail -3

# 安装运行
xcrun simctl install <simulator-id> 'build/Build/Products/Debug-iphonesimulator/AI有声书.app'
xcrun simctl launch <simulator-id> com.audiobook.ai-audiobook

# 复制测试文件（每次重装后需要重新复制）
APP_CONTAINER=$(xcrun simctl get_app_container <simulator-id> com.audiobook.ai-audiobook data)
mkdir -p "$APP_CONTAINER/Documents"
cp /path/to/test.txt "$APP_CONTAINER/Documents/"
```

### 第 2 步：导入书籍
1. 打开模拟器中的 App
2. 点右上角 **"导入TXT"** 按钮
3. 选 **"扫描本地文件"**
4. 书架出现书籍封面即成功

### 第 3 步：测试核心功能
1. 点击书籍 → 进入详情页
2. 选择章节 → 触发 AI 分析和 TTS 合成
3. 点击播放 → 测试音频输出
