第 2 步：配置 API 密钥
    1. 复制模板: cp Config.plist.template Config.plist
    2. 编辑文件: open Config.plist
    3. 填入你的 Claude API Key 和 Azure TTS Key

    - Claude: https://console.anthropic.com/
    - Azure: https://portal.azure.com/
