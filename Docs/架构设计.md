# 架构设计文档

## 系统架构概览

```
┌─────────────────────────────────────────────────────────┐
│                      用户界面层                          │
│  (小说导入、角色配置、播放控制、进度管理)                 │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│                    业务逻辑层                            │
├─────────────────────────────────────────────────────────┤
│  文本分析器  │  TTS引擎  │  音频混合器  │  播放管理器   │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│                    数据服务层                            │
│  (缓存管理、文件存储、配置管理、API调用)                 │
└─────────────────────────────────────────────────────────┘
```

## 核心模块详解

### 1. 文本分析模块 (TextAnalysis)

**职责**：
- 解析小说文本结构
- 识别对话与旁白
- 提取角色信息
- 分析情感与场景

**核心类**：
```swift
// 文本分析器
class NovelTextAnalyzer {
    func analyze(text: String) async -> AnalysisResult
}

// 分析结果
struct AnalysisResult {
    let segments: [TextSegment]
    let characters: [Character]
    let scenes: [Scene]
}

// 文本片段
struct TextSegment {
    let text: String
    let type: SegmentType  // 对话/旁白
    let speaker: Character?
    let emotion: Emotion
    let scene: Scene
}
```

**AI 分析策略**：
- 使用 Claude/GPT API 进行智能分析
- 批量处理以降低成本
- 结果缓存避免重复分析

### 2. TTS 引擎模块 (TTSEngine)

**职责**：
- 生成 SSML 标记
- 调用 TTS API
- 管理音色映射
- 优化韵律表现

**核心类**：
```swift
// TTS 引擎
class TTSEngine {
    func synthesize(segment: TextSegment) async -> AudioData
}

// SSML 生成器
class SSMLGenerator {
    func generate(segment: TextSegment, voice: Voice) -> String
}

// 音色管理器
class VoiceManager {
    func assignVoice(for character: Character) -> Voice
}
```

**支持的 TTS 服务**：
- OpenAI TTS API (推荐)
- Azure Cognitive Services
- 阿里云智能语音
- 科大讯飞

### 3. 音频混合模块 (AudioMixer)

**职责**：
- 混合语音与背景音
- 添加音效
- 调整音量平衡
- 生成最终音频

**核心类**：
```swift
// 音频混合器
class AudioMixer {
    func mix(voice: AudioData, background: AudioData) -> AudioData
}

// 场景音乐选择器
class SceneMusicSelector {
    func selectMusic(for scene: Scene) -> AudioData
}
```

**音频处理**：
- 使用 AVFoundation 进行混音
- 支持淡入淡出效果
- 自动音量归一化

### 4. 播放管理模块 (Player)

**职责**：
- 音频播放控制
- 进度管理
- 缓存策略
- 后台播放

**核心类**：
```swift
// 播放器
class AudioBookPlayer {
    func play()
    func pause()
    func seek(to position: TimeInterval)
}

// 缓存管理器
class AudioCacheManager {
    func cache(audio: AudioData, for segment: TextSegment)
    func retrieve(for segment: TextSegment) -> AudioData?
}
```

## 数据流程

### 完整处理流程

```
1. 用户导入小说文本
   ↓
2. 文本分析器解析文本
   - 分段（章节、段落）
   - 识别对话与旁白
   - 提取角色
   - 分析情感和场景
   ↓
3. 用户配置角色声线（可选）
   ↓
4. TTS 引擎生成语音
   - 为每个片段生成 SSML
   - 调用 TTS API 合成
   - 缓存音频数据
   ↓
5. 音频混合器处理
   - 选择背景音乐
   - 混合语音与音乐
   - 添加音效
   ↓
6. 播放器播放
   - 流式播放
   - 进度保存
   - 支持快进/后退
```

## 性能优化策略

### 1. 分段处理
- 按章节或段落分段
- 避免一次性处理整本小说
- 支持增量生成

### 2. 智能缓存
- 已生成的音频持久化
- LRU 缓存策略
- 支持离线播放

### 3. 并发处理
- 多个片段并行生成
- 异步 API 调用
- 后台队列处理

### 4. 成本控制
- 文本分析结果缓存
- 批量调用 API
- 可选的本地 TTS 降级方案

## 技术选型

### iOS 框架
- **SwiftUI**: 现代化 UI 框架
- **Combine**: 响应式编程
- **AVFoundation**: 音频处理
- **CoreData**: 本地数据持久化

### 第三方依赖
- **Alamofire**: 网络请求
- **SwiftyJSON**: JSON 解析
- **Kingfisher**: 图片缓存（封面等）

### AI 服务
- **OpenAI API**: 文本分析 + TTS
- **Claude API**: 文本分析（备选）

## 扩展性设计

### 插件化架构
- TTS 引擎可插拔
- 支持多种 AI 分析服务
- 自定义音效库

### 配置化
- 用户可自定义角色声线
- 可调整背景音乐风格
- 语速、音调可配置

## 安全与隐私

- 用户文本本地处理
- API 密钥安全存储
- 可选的完全离线模式
