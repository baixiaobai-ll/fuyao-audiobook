# 当前待办优先级

这份清单只保留“扶摇”当前阶段最值得继续推进的事项。

原则：

- 优先影响真实用户体验
- 优先补主链路稳定性
- 不把愿望清单和商业化远期事项混进来

## P0：先验证与修正主链路

### 1. 完整回归测试搜索与播放主路径

目标：

- 验证“发现”页真实搜索是否稳定
- 验证长章节是否能分批生成并连续播放
- 验证章节切换、进度保存、再次进入播放页是否正常

为什么优先：

这是目前最接近真实用户感知的主链路，任何问题都会直接影响可用性。

重点文件：

- [BookSearchView.swift](/path/to/Desktop/AI有声书项目/App/BookSearchView.swift)
- [BookChapterPlayback.swift](/path/to/Desktop/AI有声书项目/App/BookChapterPlayback.swift)
- [NowPlayingView.swift](/path/to/Desktop/AI有声书项目/App/NowPlayingView.swift)

### 2. 补齐长章节体验提示与边界处理

目标：

- 在 UI 上明确告诉用户“章节正在分批生成”
- 处理生成失败、取消、超长章节等待时的状态提示
- 避免用户误以为章节只生成了一部分

为什么优先：

现在底层已经支持分批生成，但用户感知层还不够完整。

重点文件：

- [BookDetailView.swift](/path/to/Desktop/AI有声书项目/App/BookDetailView.swift)
- [BookChapterPlayback.swift](/path/to/Desktop/AI有声书项目/App/BookChapterPlayback.swift)

## P1：提高稳定性和可维护性

### 3. 收敛发现页书源策略

目标：

- 明确真实搜索、分类推荐、缓存回退三者的优先级
- 统一错误提示
- 为后续多书源或代理层预留接口

为什么优先：

发现页目前已经可用，但书源波动会直接影响搜索和找书体验。

重点文件：

- [BookSourceEngine.swift](/path/to/Desktop/AI有声书项目/Sources/Bookshelf/BookSourceEngine.swift)
- [DiscoverAPIClient.swift](/path/to/Desktop/AI有声书项目/Sources/Bookshelf/DiscoverAPIClient.swift)
- [BookSearchView.swift](/path/to/Desktop/AI有声书项目/App/BookSearchView.swift)

### 4. 处理共享层中的并发与警告债务

目标：

- 清理 `swift build` 中当前残留的关键 warning
- 重点处理 `AudioBookGenerator` 里异步上下文使用 `NSLock` 的问题
- 保持共享层编译检查持续可用

为什么优先：

这是后续继续迭代共享层时的工程稳定基础。

重点文件：

- [AudioBookGenerator.swift](/path/to/Desktop/AI有声书项目/Sources/AudioBookGenerator.swift)
- [AudioMixer.swift](/path/to/Desktop/AI有声书项目/Sources/AudioMixer/AudioMixer.swift)
- [Config.swift](/path/to/Desktop/AI有声书项目/Sources/Config.swift)

## P2：增强产品完成度

### 5. 提升本地 TXT 导入和章节切分质量

目标：

- 优化章节识别规则
- 改善对序章、卷名、番外、非标准章节名的兼容
- 降低“按长度硬切”带来的阅读割裂感

为什么优先：

本地导入是扶摇的重要入口之一，切分质量会直接影响听书体验。

重点文件：

- [BookshelfView.swift](/path/to/Desktop/AI有声书项目/App/BookshelfView.swift)

### 6. 增强“扶摇”的产品表达

目标：

- 在首页、播放页或详情页更清楚地表达多角色、情绪化、边生成边播这些差异化价值
- 让用户理解扶摇不是普通播放器，而是“生成式听书”

为什么优先：

技术能力已经不少，但产品表达还没有完全跟上。

重点文件：

- [ContentView.swift](/path/to/Desktop/AI有声书项目/App/ContentView.swift)
- [BookDetailView.swift](/path/to/Desktop/AI有声书项目/App/BookDetailView.swift)
- [NowPlayingView.swift](/path/to/Desktop/AI有声书项目/App/NowPlayingView.swift)

## 暂时不优先

以下事项先不放进当前最高优先级：

- iCloud 云同步
- 小组件
- 应用内购买
- 分享功能
- 大规模商业化相关能力
- 为了工程“好看”而进行的大范围结构重写

这些方向不是不做，而是应该排在主链路稳定和体验清晰之后。
