## 开发环境要求

### 必需
- macOS 13.0+
- Xcode 14.0+
- Swift 5.7+
- iOS 15.0+ (目标平台)

### 推荐
- Xcode 15.0+
- Swift 5.9+
- iOS 16.0+

## 安装 Xcode

1. 打开 Mac App Store
2. 搜索 "Xcode"
3. 点击 "获取" 或 "下载"
4. 等待下载完成（约 12 GB）
5. 安装完成后，打开 Xcode 并同意许可协议

## 创建 iOS 项目

### 方式 1: 使用 Xcode（推荐）

1. 打开 Xcode
2. File → New → Project
3. 选择 "iOS" → "App"
4. 填写项目信息：
   - Product Name: AI有声书
   - Team: 选择你的开发团队
   - Organization Identifier: com.yourcompany
   - Interface: SwiftUI
   - Language: Swift
5. 选择保存位置（选择我们创建的项目目录）
6. 点击 "Create"

### 方式 2: 手动集成到现有项目

如果你已有 iOS 项目，可以直接将 `Sources/` 目录下的文件添加到项目中：

1. 在 Xcode 中打开你的项目
2. 右键点击项目导航器中的文件夹
3. 选择 "Add Files to..."
4. 选择 `Sources/` 目录下的所有 `.swift` 文件
5. 确保 "Copy items if needed" 被勾选
6. 点击 "Add"

## 配置项目

### 1. 设置 Info.plist

添加必要的权限：

```xml
<key>NSMicrophoneUsageDescription</key>
<string>需要访问麦克风以录制音频</string>

<key>UIBackgroundModes</key>
<array>
    <string>audio</string>
</array>
```

### 2. 配置 API 密钥

参考 `Docs/API密钥配置.md` 文档配置你的 API 密钥。

### 3. 添加资源文件

将背景音乐和音效文件添加到项目：

1. 在 Xcode 中右键点击项目
2. 选择 "Add Files to..."
3. 选择 `Resources/` 目录
4. 确保 "Create folder references" 被选中
5. 点击 "Add"

创建测试文件：

```swift

class TextAnalysisTests: XCTestCase {
```

## 常见问题

### Q: 编译错误 "Cannot find type 'XXX' in scope"

A: 确保所有 `.swift` 文件都已添加到项目中。

### Q: 运行时崩溃 "API Key not found"

A: 检查 API 密钥配置是否正确。

### Q: 音频播放没有声音

A: 检查：
1. 设备音量是否打开
2. 音频会话是否正确配置
3. 音频文件是否存在

### Q: 内存占用过高

A: 优化建议：
1. 启用缓存
2. 及时释放不用的音频数据
3. 使用流式处理

## 性能优化

### 1. 并发处理

```swift
// 并发生成多个片段
await withTaskGroup(of: AudioData.self) { group in
    for segment in segments {
        group.addTask {
            try await ttsEngine.synthesize(segment: segment, voice: voice)
        }
    }
}
```

### 2. 缓存策略

```swift
// 启用所有缓存
let analysisCache = AnalysisCache()
let ttsCache = TTSCache()

// 定期清理
ttsCache.clearAll()  // 清理旧缓存
```

### 3. 内存管理

```swift
// 使用 autoreleasepool 处理大量数据
for segment in segments {
    autoreleasepool {
        let audio = try await synthesize(segment)
        process(audio)
    }
}
```
