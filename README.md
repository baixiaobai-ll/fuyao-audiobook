# AI 有声书项目

将文本小说转化为高质量有声小说的 iOS 应用

## 功能特性

- 📖 文本小说导入与解析
- 🎭 智能角色识别与多声线配音
- 🎵 场景化背景音乐自动匹配
- 🎤 情感化语音合成（抑扬顿挫）
- 🎧 高质量音频输出与播放

## 技术架构

### 1. 文本处理模块
- 小说文本解析
- 对话与旁白识别
- 角色提取与映射
- 情感与场景分析

### 2. 语音合成模块
- AI TTS 服务集成
- SSML 标记生成
- 多角色声线管理
- 韵律优化

### 3. 音频处理模块
- 背景音乐混合
- 音效添加
- 音频缓存管理

### 4. 播放控制模块
- 音频播放器
- 进度管理
- 离线缓存

## 开发环境

- Xcode 14.0+
- iOS 15.0+
- Swift 5.7+

## 项目结构

```
Sources/
├── TextAnalysis/      # 文本分析模块
├── TTSEngine/         # 语音合成引擎
├── AudioMixer/        # 音频混合器
├── Player/            # 播放器
└── UI/                # 用户界面

Resources/
├── BackgroundMusic/   # 背景音乐库
├── SoundEffects/      # 音效库
└── Voices/            # 声音配置

Tests/
├── TextAnalysisTests/
├── TTSEngineTests/
└── AudioMixerTests/
```
